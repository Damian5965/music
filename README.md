# 808.SCHOOL — лендинг с драм-машиной

Одностраничный лендинг школы битмейкинга. Вся вёрстка, стили и логика находятся в `index.html` — отдельная сборка не нужна.

В блоке `#demo` работает интерактивная драм-машина на Web Audio API: 7 дорожек × 16 шагов, пресеты, BPM/swing/volume, тон 808, mute, аудирование, рандом, автосохранение паттерна в `localStorage` и экспорт лупа в WAV. Визуально она оформлена как настоящий «железный» грувбокс: брашированный металл, деревянные боковые накладки, винты, резиновые пэды с LED, фейдеры и LCD-монитор.

Локальный просмотр:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем открыть `http://localhost:8000/`.
